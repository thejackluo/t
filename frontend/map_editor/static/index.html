GOOGLE MAPS & MY MAPS

Your tracks, on the map.

Use your existing Google My Maps project:

  1. Create your itinerary here, then choose Export to My Maps.
  2. Open your Google My Maps project ↗ and sign in.
  3. Choose Add layer → Import, then select the downloaded KML file. Rail lines follow MBTA track shapes.

Want the whole rail network as a reference layer? Download MBTA rail tracks & stations KML. Keep it in a separate My Maps layer. My Maps does not automatically snap newly drawn lines to subway tracks; create the rail paths here and import them.

Google map inside this editor

  1. Open Google Maps Platform setup ↗. Sign in, create/select a project, and attach billing.
  2. Enable Maps JavaScript API.
  3. Open APIs & Services → Credentials, choose Create credentials → API key, and edit the key.
  4. Under application restrictions choose Websites. Add http://127.0.0.1:8001/* (this page's origin) plus any other origin you use, such as http://localhost:8001/*.
  5. Under API restrictions choose Restrict key → Maps JavaScript API, then save. Allow a few minutes for changes to apply.
  6. Paste the browser key below and load the map. Google Maps becomes the background; your MBTA tracks and itinerary stay on top.

With Remember on this device the key is kept in this browser's local storage so you are not asked again; otherwise it lasts for this tab only. It is never included in scenario saves or exports. To skip the prompt entirely on a deployment, set GOOGLE_MAPS_API_KEY in the server environment (Vercel → Project → Environment Variables) and redeploy. For Suggest streets, also enable Routes API and add it to the key's API restrictions.

Editing foot paths

Select Edit foot path on a run/walk segment. Click the preview map to add waypoints; drag the purple handles to move them. On Google Maps, drag its editable path handles. A two-point sketch is straight-line geometry, not a verified street route. Google pedestrian suggestions are session-only and are omitted from geometry exports.

Time conventions

Times are America/New_York service hours: 25:15 is 1:15 AM the next day. Date changes recompute every connection. Plan duration includes preparation; the first-train → last-platform schedule proxy is shown separately. Actual door/platform boundary allowances are not measured here.
